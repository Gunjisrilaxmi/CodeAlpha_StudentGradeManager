# 🎓 Student Grade Manager (Java Project)

## 📌 Project Overview
The **Student Grade Manager** is a simple Java console-based application that helps manage student records and their marks. It calculates important statistics such as **average, highest, and lowest scores**, and displays a complete summary report.

This project is built as part of my internship task at **CodeAlpha**.

---

## 🚀 Features
- Add multiple student records
- Store data using ArrayList
- Display all student details
- Calculate:
  - 📊 Average marks
  - 🏆 Highest marks
  - 📉 Lowest marks
- Simple console-based interface

---

## 🛠️ Technologies Used
- Java (Core Java)
- ArrayList
- Scanner class (for input)
